# The Blueprint Portfolio

When you browse developer portfolios, a pattern emerges: near-black backgrounds, neon cyan/orange accents, gradient blobs, and somewhere in the center a large italic serif saying "I ship things."

It works, but it also means **every portfolio looks like every other portfolio**.

## This one, different

For my own site I wanted something that actually *sounded* like what I do — software, game engines, ML tooling — without being literal about it. The answer landed on a blueprint / engineering schematic aesthetic.

Deep ink background (`#0a0c10`), paper-colored spec-sheet panels, structural drafting lines in blue-grey, and a single terracotta accent color for everything interactive. Section headers read `FIG. 02 — PROJECTS` in mono font. Dividers are dimension-line style.

No rounded pill buttons. No gradient text. No stock illustrations. Just a clean, legible technical document that happens to be a personal portfolio.

## Small touches, bigger effect

Gamification wasn't an afterthought either. RPG-style skill bars, pixel-art corner brackets that flash terracotta on hover, a Konami code easter egg (`↑↑↓↓←→←→BA` — try it). None of it is noisy. It's just enough to make someone lean in.

The whole thing builds to a static `dist/` folder and ships on Vercel. Fast, cheap, no backend to manage.

That's the pitch anyway. See it live at [udays.space](https://udays.space).
